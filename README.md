# Negocios Escobar

Dashboard local para gestionar prestamos, cobros, clientes, caja, gastos y reportes.

## Como abrir

Abre `index.html` en Google Chrome o Microsoft Edge. La app guarda los datos en el navegador usando `localStorage`.

## Herramientas incluidas

- Prestamos diarios, semanales y mensuales.
- Interes porcentual y cronograma automatico de cuotas.
- Opcion de no cobrar domingos en prestamos diarios.
- Registro de cobros completos o parciales.
- Resumen de pagos adelantados para saber cuantas cuotas cubrio un cobro grande.
- Boton de WhatsApp para enviar recordatorios de cuota al cliente.
- Reloj en tiempo real con hora de Peru.
- Boton de notificaciones para cuotas vencidas y proximas.
- Clientes con celular, zona y direccion.
- Caja calculada con caja inicial, desembolsos, cobros, ingresos y gastos.
- Alertas de cuotas vencidas y cobros del dia.
- Reportes por mes y grafico de cobros recientes.
- Exportacion CSV para abrir en Excel.
- Respaldo JSON e importacion para recuperar datos.
- Vista imprimible del modulo actual.

## Recomendacion

Usa `Ajustes > Exportar JSON` al final de cada dia para tener un respaldo fuera del navegador.
